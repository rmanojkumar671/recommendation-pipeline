# Data samples

The first 20 rows of every table the pipeline produces, plus the metadata files of each stage. The full data is **not committed**: the MovieLens licence does not allow redistribution, and every derived file is regenerated by `python run_pipeline.py` (about 1 minute). Regenerate these samples with `python -m src.utils.export_samples`.

Note: `1_ingestion/interactions_sample.csv` is the raw file *after* the documented noise injection, so it may contain corrupted rows; `data/errors/` shows what validation quarantined.
